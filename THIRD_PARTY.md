# Third-party code

model3recomp is MIT licensed. The sound board carries code from elsewhere,
under the licences below; each file keeps its own notice.

| Where | What | Licence |
|---|---|---|
| `src/m68k/` | [Musashi](https://github.com/kstenerud/Musashi) 4.60, Karl Stenerud's 68000 emulator, built for the 68000 only. `m68kops.c` / `.h` are generated by its `m68kmake`; `m68kconf.h` is configured for this project. | MIT -- `src/m68k/LICENSE` |
| `src/m68k/softfloat/` | SoftFloat 2b, John R. Hauser, as packaged with Musashi. Linked because Musashi's FPU code refers to it; a 68000 never executes it. | SoftFloat licence -- `src/m68k/softfloat/README.txt` |
| `src/scsp.c` | A C port of MAME's `scsp.cpp` and `scspdsp.cpp` (ElSemi, R. Belmont, kingshriek). | BSD-3-Clause -- the notice at the top of the file |
| `src/sound.c` | The sound board's wiring follows MAME's `sega/model3.cpp` (R. Belmont, Ville Linde). | BSD-3-Clause |
| `src/real3d.c` | The texture tile decode tables (`TILE16`, `TILE8`) are MAME's from `sega/model3_v.cpp` (R. Belmont, Ville Linde); the texture upload, mipmap layout, node walk, header and viewport word meanings follow that file's code and documentation. | BSD-3-Clause -- the notice at the top of `src/scsp.c` |
| `src/tilegen.c` | Layer pairing, stencil, scroll and register meanings follow MAME's `sega/model3_v.cpp`. | BSD-3-Clause |

## Supermodel

Versions of this library published before October 5, 2026 contained
code derived from [Supermodel](https://github.com/trzy/Supermodel), which is
GPL-licensed, without saying so -- the renderer's texture and texel
decoding, node walk, frustum, fog, specular and mipmap handling, the tilemap
line drawing, the 93C46 EEPROM and the light gun reload and calibration.
That was wrong, and it has been removed: every one of those parts was
rewritten from MAME (BSD-3-Clause) or from measurements of the game, and
no code from Supermodel remains. The repository's history was then squashed
so that it no longer carries the old code. See the changelog.
